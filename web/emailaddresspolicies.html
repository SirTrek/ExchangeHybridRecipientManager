Email Address Policies

The rules that generate recipients' email addresses. Exchange applies the first policy whose recipient filter matches; the default policy is always last.

Name Priority Recipient filter
New policy
Lower numbers are applied first. Exchange keeps priorities in a single unbroken run, so only the values listed are accepted - the last one appends this policy to the end.
The address format this policy stamps on matching recipients. Exchange needs this to create a policy at all. %m = alias, %g = first name, %s = last name, %1g = first initial. For example %g.%s@contoso.com gives jane.doe@contoso.com. The domain must already be an accepted domain.
