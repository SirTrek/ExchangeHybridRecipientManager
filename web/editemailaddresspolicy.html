One per line. Exactly one must use an upper-case SMTP: prefix — that is the primary reply address; use lower-case smtp: for the rest. A template with no local part, such as SMTP:@contoso.com, uses the recipient's Alias. Otherwise %m is the alias, %g the given name, %s the surname and %1g the first initial — for example SMTP:%g.%s@contoso.com. Changes here do not touch existing recipients; they apply to recipients written afterwards. The domain must already be an accepted domain.
